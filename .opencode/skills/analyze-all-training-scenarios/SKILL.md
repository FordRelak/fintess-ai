# Анализ всех сценариев

Выполните один изолированный запуск `analyze-training-progress` для каждого доступного `metrics.json`.

## Процесс

1. Найдите все файлы `result.json` внутри `/Users/mfedchenkov/Projects/fintess-ai/eval/scenarios` рекурсивно и удалите их. Сначала завершите удаление всех найденных файлов.
2. Найдите все файлы `metrics.json` внутри `/Users/mfedchenkov/Projects/fintess-ai/eval/scenarios` рекурсивно.
3. Для каждого найденного `metrics.json` создайте отдельного саб-агента. Запустите всех саб-агентов одним параллельным вызовом `Task`; не ждите завершения одного запуска перед созданием следующего.
4. Поручите каждому саб-агенту применить `analyze-training-progress` только к переданному точному пути `metrics.json` и записать `result.json` рядом с ним.
5. Дождитесь завершения всех саб-агентов и завершите работу.

## Жёсткие границы

- Не читайте содержимое `result.json` до, во время или после запусков.
- Не запускайте evaluator, validator или другие действия над результатами.
- Не сравнивайте результаты между сценариями.
- Не исправляйте, форматируйте и не удаляйте созданные результаты.
- Не выполняйте дополнительные действия после завершения параллельных запусков.

## Критерий завершения

Работа завершена, когда каждый найденный после очистки `metrics.json` передан ровно одному параллельно запущенному саб-агенту с `analyze-training-progress`; содержимое и статус созданных `result.json` не проверяются.
